# PepsiCo Social Media Analytics Project

## 📌 Project Overview
An Excel-based Social Media Intelligence Solution built for PepsiCo 
to analyze digital marketing performance across Instagram, Twitter, 
Facebook, and YouTube.

## 🎯 Objectives
- Identify best-performing content types
- Optimize advertising budget allocation
- Track audience growth and loyalty
- Measure campaign impact on brand reach

## 📊 Tasks Covered
- Task 1: Data Preprocessing & Cleaning
- Task 2: Engagement Analysis
- Task 3: Platform Performance Analysis
- Task 4: Hashtag & Content Strategy
- Task 5: Campaign Effectiveness
- Task 6: Follower Retention & Audience Loyalty

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Charts, Formulas)

## 📁 Dataset
PepsiCo Marketing Dataset (Posts, Engagement Summary, Campaign Metadata)
